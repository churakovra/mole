# Security policy

This repository currently contains a release candidate, not a security-certified
stable release. See [the security model](docs/security-model.md) for concrete
controls and limitations, and [release readiness](docs/release-readiness.md) for
unexecuted checks.

Report suspected vulnerabilities privately to the repository owner through an
available private contact channel. Include the affected revision, minimal inert
reproduction, expected/observed behavior, and impact. Do not publish credentials,
private source, personal data, or a weaponized exploit in a public issue.

Relevant issues include source execution, hidden network/installation, secret
disclosure, filesystem escape, output injection, corruption, or loss of authored
notes. Semantic inaccuracies should include the source evidence and a concrete
counterexample. No response-time commitment or supported-version window is
claimed before the first accepted stable release.
